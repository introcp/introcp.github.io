Recap: Binary Numbers¶

Number Systems: Positional vs. Non-Positional¶

  • Non-Positional Systems: The value of a symbol is independent of its position.

    • Example: In the Roman numeral XXVIII (28)

      • both X symbols represent 10


  • Positional Systems: The value of a symbol depends on its position within the number.

    • Example: In the decimal number 37579:

      • the first 7 represents 7000

      • while the second 7 represents 70

General Positional System¶

  • Any natural number b>1b > 1b>1 can be used as the base of a positional number system.

  • A number is written as a sequence of digits dn−1dn−2...d1d0d_{n-1}d_{n-2}...d_1d_0dn−1​dn−2​...d1​d0​, where each digit did_idi​ is an integer from 0 to b−1b-1b−1.

  • The value of the number is calculated using the formula:

    N=∑i=0n−1di×bi=dn−1bn−1+dn−2bn−2+⋯+d1b1+d0b0N = \sum_{i=0}^{n-1} d_i \times b^i = d_{n-1}b^{n-1} + d_{n-2}b^{n-2} + \dots + d_1b^1 + d_0b^0N=i=0∑n−1​di​×bi=dn−1​bn−1+dn−2​bn−2+⋯+d1​b1+d0​b0

The Binary System (Base 2)¶

When the base b=2b=2b=2, we get the binary system. The only possible digits are 0 and 1.

Bits and Bytes¶

  • Bit: A single binary digit (0 or 1).

  • Byte: A group of 8 bits.

With one byte, we can represent 28=2562^8 = 25628=256 different values (from 0 to 255). This is enough to represent all the characters on a standard keyboard using an encoding like ASCII.

Octal and Hexadecimal Systems¶

These systems are commonly used in computing as a compact way to represent binary numbers.

  • Octal: Uses b=8b=8b=8 and digits 0-7.

  • Hexadecimal: Uses b=16b=16b=16 and digits 0-9 and letters A-F, where:

    • A = 10, B = 11, C = 12, D = 13, E = 14, F = 15

Converting from Decimal to Another Base¶

To convert a decimal number N10N_{10}N10​ to base bbb, we use the method of successive divisions:

  1. Divide N10N_{10}N10​ by the base bbb. The remainder is the rightmost digit.

  2. Replace N10N_{10}N10​ with the quotient from the division.

  3. Repeat until the quotient is 0. The remainders, read in reverse order, form the number in base bbb.

Example: Convert 11610 to Binary¶

116÷2=58⇒116 \div 2 = 58 \Rightarrow116÷2=58⇒ remainder 0

58÷2=29⇒58 \div 2 = 29 \Rightarrow58÷2=29⇒ remainder 0

29÷2=14⇒29 \div 2 = 14 \Rightarrow29÷2=14⇒ remainder 1

14÷2=7⇒14 \div 2 = 7 \Rightarrow14÷2=7⇒ remainder 0

7÷2=3⇒7 \div 2 = 3 \Rightarrow7÷2=3⇒ remainder 1

3÷2=1⇒3 \div 2 = 1 \Rightarrow3÷2=1⇒ remainder 1

1÷2=0⇒1 \div 2 = 0 \Rightarrow1÷2=0⇒ remainder 1

Reading the remainders from bottom to top, we get: (1110100)2(1110100)_2(1110100)2​.

Example: Convert 154710 to Hexadecimal¶

1547÷16=96⇒1547 \div 16 = 96\Rightarrow1547÷16=96⇒ remainder 11 (which is B in hex)

96÷16=6⇒96 \div 16 = 6\Rightarrow96÷16=6⇒ remainder 0

6÷16=0⇒6 \div 16 = 0\Rightarrow6÷16=0⇒ remainder 6

Reading the remainders from bottom to top, we get: (60B)16(60B)_{16}(60B)16​.

Recap: Boolean Logic¶

Boolean Operators and Truth Tables¶

Boolean algebra operates on truth values (True/1, False/0) using logical operators.

  • AND (Conjunction, ∧\land∧): True only if both operands are true.

  • OR (Disjunction, ∨\lor∨): True if at least one operand is true.

  • NOT (Negation, ¬\neg¬): Inverts the truth value.

Key Concepts in Boolean Logic¶

  • Equivalence: Two expressions are equivalent if they have the same truth table.

    • Example (De Morgan’s Law): ¬(A∨B)≡¬A∧¬B\neg(A \lor B) \equiv \neg A \land \neg B¬(A∨B)≡¬A∧¬B

  • Tautology: An expression that is always true, regardless of the input values.

    • Example: A∨¬AA \lor \neg AA∨¬A

  • Contradiction: An expression that is always false.

    • Example: A∧¬AA \land \neg AA∧¬A
