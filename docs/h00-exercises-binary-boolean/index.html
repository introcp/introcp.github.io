Decimal 387 to Binary¶

Convert the decimal number 387 to binary:

387÷2=193387 \div 2 = 193387÷2=193 (rem 1)

193÷2=96193 \div 2 = 96193÷2=96 (rem 1)

96÷2=4896 \div 2 = 4896÷2=48 (rem 0)

48÷2=2448 \div 2 = 2448÷2=24 (rem 0)

24÷2=1224 \div 2 = 1224÷2=12 (rem 0)

12÷2=612 \div 2 = 612÷2=6 (rem 0)

6÷2=36 \div 2 = 36÷2=3 (rem 0)

3÷2=13 \div 2 = 13÷2=1 (rem 1)

1÷2=01 \div 2 = 01÷2=0 (rem 1)
